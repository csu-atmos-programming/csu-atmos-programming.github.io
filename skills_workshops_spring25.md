2) LaTeX and Markdown (and Tools for Using Them) - Fri, Mar 7th, 1:00-3:00 pm in ATS West 121
3) Version Control and Unit Testing with Git and GitHub Actions - Fri, Apr 11th, 1:00-3:00 pm in ATS West 121
